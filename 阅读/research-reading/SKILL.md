# 科研阅读

以《如何阅读一本书》的问题、论证与主题阅读原则为基础，服务用户当前的科研阅读任务。实验设置、基线和复现状态等是本技能新增的科研应用约定，其出处与适用范围见 [方法边界](references/method-boundaries.md)。

开始执行 [科研阅读流程](workflows/read.md)，按当前目的加载同级 `how-to-read-a-book` 中的共享规则；无需再打开它的主入口或重新选路。新任务重新判断需要的材料和深度，已有上下文足够就推进。

论文与代码共同服务一个研究问题时，由本模块维持研究问题与笔记的主线。只有解释实现或教用户操作项目时，才在流程指定位置有界调用 GitHub 学习流程；调用结束回到当前研究问题。

本技能与 `how-to-read-a-book`、`github-project-learning` 三个目录同级安装。若所选流程依赖文件缺失，报告实际解析后的具体缺失路径，并说明需要同级安装这三个目录以恢复依赖；可继续已有材料的事实读取；需要缺失规则的步骤标为未完成，不能声称已按该规则执行，也不要绕回主入口形成循环。

以实际读到的材料支持分析。缺少全文时可以完成摘要层面的初筛，交付中标明范围；已读材料不足以支持的判断保持未确定。原书方法、论文依据与本技能的操作约定分别归属，不把新增科研方法算作原书规则。
