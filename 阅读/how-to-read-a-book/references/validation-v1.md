# 1.0 版本历史验证记录

这是拆分前 1.0 版本的历史记录，不能证明新增科研或 GitHub 流程已通过验证。

日期：2026 年 9 月 12 日。成品为一个按任务与书类选路的阅读 skill，共 132 条提炼规则、510 处原文短摘、6 条主流程。入口正文 29 行，详细规则按需加载。132 是本次整理的数量，不是作者原有的正式编号。

## 原文与语义

四名代理分工精读该中文版本的 21 章、序言与两份附录；分段资料包含 2,271 个非空段落对象。书目、练习、案例和背景也纳入阅读，但只将有依据的阅读动作提炼为规则。逐章覆盖及未提取原因见 [coverage.md](coverage.md)。

三个提取组交换规则，对照全部引证段落的完整内容及必要相邻上下文进行语义核验，随后检查合并后的规则和流程：

- [基础与主题规则交叉审查](review-notes/cross-foundation-synthesis.md)：43 条初稿规则。
- [分析阅读交叉审查](review-notes/cross-analysis.md)：40 条初稿规则。
- [分书类交叉审查](review-notes/cross-genres.md)：54 条初稿规则。
- [整合审查](review-notes/integration-review.md)：检查去重、规则条件及流程中的实际指令。

137 条初稿合并 5 处重复责任后为 132 条，来源证据保留。修复包括关键字查词例外、作者自序与他人导读的区别、重读按需要而非强制二遍、诗歌冲突的非普遍性、定案本传记的对象限制，以及文学、实用书和摘要使用的适用范围。原书内部两处不一致保留在覆盖说明中，未擅改原译文。

## 实际使用验证

一名未参与提炼的独立代理，仅依据技能与给定最小材料，对 8 个请求实际作答。发现节选练习与书类方法咨询的条件加载提示不足，修正路由后复测 3 个相关请求，再新增重读条件回归案例。主代理读回全部回答。

| 场景 | 最终观察 |
| --- | --- |
| T01：只有目录，时间有限 | 作局部检视，指出无法裁定未见的完整论证。 |
| T02：完整微型小说 | 按作品经验、情节和有理由的喜恶分析；区分人物发言和叙述事实。 |
| T03：自然与约定的表面冲突 | 辨别两个问题，保留局部相容与全书立场未定；不把节选练习冒充完整研究。 |
| T04：笔记把未调查推成全错 | 回原文纠正记忆及推理跳步，区分明确范围与不完整批评。 |
| T05：难书首遍查词与导读 | 保留关键字例外，区分作者自序和他人导读。 |
| T06：数学学习想跳过所有证明 | 直接加载数学规则，按学习目标保留证明阅读。 |
| T07：看懂助手笔记是否等于已掌握 | 不认证已读懂或没读懂，提出读者独立回答及原文核验任务。 |
| T08：不认同实用书的目标 | 分开目标价值与方法有效性，保留有条件的行动要求。 |
| T09：初步了解后是否必须二读 | 当前目的满足即可结束，重读由后续问题与目标决定。 |

试用的全部 [请求与材料](evaluation-cases.json)、[初次回答及复测回答](evaluation-responses.json) 可检查；测试用虚构材料均已明确标识。9 个场景中未见剩余实质问题，这些结果只证明所列场景的表现，不能认证未来所有书的解读或用户已经掌握。
