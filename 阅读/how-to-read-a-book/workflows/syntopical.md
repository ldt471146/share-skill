# 主题阅读

读 [阅读目标与基础](../rules/reading-core.md) 和 [主题阅读规则](../rules/syntopical.md)。主题阅读以待研究的问题为中心。以下步骤可以相互调整、返回修正，准备阶段的候选书检视仍须完成。

若只提供已选节选来练习或做局部比较，先读 [理解检验依据](../rules/understanding-checks.md) 的 S27，完成材料允许的比较并标范围。真实完整主题研究才把以下全部准备与研究工作纳入完成条件。

1. 依据已有材料形成暂定主题与候选书目；检视候选材料，修正主题、筛除不相关书。主题与书目可以互相校准。
2. 再检视已选相关作品，定位与问题相关的段落；不为此先逐本完整分析全部著作。
3. 建立中立的工作词汇，说明每位作者的原词怎样对应，保留不可合并的词义差别。
4. 提出各作者能够回答的中立问题，从相关段落提取回答；区分明确回答、有文本依据的间接回答、沉默及未定；给出间接回答时说明推解依据，不强填立场。后续问题尊重作者此前的回答。
5. 确认作者在同一意义上回答同一问题后，才组成冲突议题。整理不同回答和支撑理由，安排基础/从属、共识/分歧之间的关系。
6. 呈现问题怎样被澄清及仍待研究的部分。作者立场的解释旁应有相关原文和定位，供读者检核。

处理具体书类的解释难点时按 routing.yaml 加载对应书类；需要跨书笔记时读 [笔记与练习](../rules/notes-and-practice.md)。

按需交付“问题—作者回答—原文依据—理由—分歧”的可比较结果。表格仅在确实便于比较时使用。

核对：是否把同词当成同义、把异词当成对立、凭沉默补立场；是否强迫所有作者回答同样的问题或站队；是否把研究者的偏好写成书中已达成的结论。主题研究本身不以裁定最终真理作为完成条件。

生成、更新或核对笔记时，再按 [公共笔记约定](../references/note-contract.md) 组织来源、范围、解释与评价。
