# 检视阅读

读 [阅读目标与基础](../rules/reading-core.md) 和 [检视规则](../rules/inspection.md)。

1. 确认可用材料和时间，以实际见到的书名页、序、目录、索引、章节及结尾执行系统略读；没有的部分标缺失。目的在建立类别、主题与架构，决定进一步投入。
2. 若进入难书首遍粗浅阅读，先建立通读的整体；把尚未理解的地方留待后续按需要重读。若用户询问查词、导读或外援，补读 [辅助阅读](../rules/reading-aids.md) 以保留查词时机的例外。
3. 若需要记录，按 [笔记与练习](../rules/notes-and-practice.md) 做结构笔记。时间不足完成通读时如实标明已读范围。

交付内容依实际任务选择：书类、主题的一句话初判、主要部分与关系、继续阅读的理由、待解问题。初步分类和概括均应能指回已读材料。

核对：是否把书的宣传当成正文证据，是否因局部不懂停滞，是否在检视后过早赞同或反对作者。用户转向深读时回到 routing.yaml 选择适当流程。

生成、更新或核对笔记时，再按 [公共笔记约定](../references/note-contract.md) 组织来源、范围、解释与评价。
