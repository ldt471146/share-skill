# 核对理解

读 [阅读目标与基础](../rules/reading-core.md)、[笔记与练习](../rules/notes-and-practice.md) 和 [理解检验依据](../rules/understanding-checks.md)。

以下是把原书自我要求原则落实到对话的操作约定：

1. 对齐用户的笔记、回答或摘要与实际已读原文，确认这是检视后的理解、单书分析、文学阅读还是主题比较。
2. 按该类结果加载相应规则：论说书的分析与批评读 [分析阅读](../rules/analysis.md)，文学读 [文学规则](../rules/genres/literature.md)，跨书比较读 [主题阅读](../rules/syntopical.md)。
3. 先指出已准确掌握且有出处的部分；对错误、跳步或证据不足，指出具体原文及其改变判断的原因。区分记忆错误、词义混淆、推理问题和材料不足。
4. 要检验用户是否理解，可请其围绕当前关键处用自己的话解释、举适合的例子或还原一个理由链。根据回答回到原文核对；不直接把标准答案出现视为用户通过。
5. 确认已解决的误读与仍需重读的部分，给下一步阅读建议。需要长期选书或练习时转 [能力练习](practice.md)。

核对范围随材料确定。未看过原文时，可以评估笔记的内部关系和提出核验位置，不能认证忠实于全书。原附录练习的题目、时间和条件不转成所有书的固定考试；不编造通用掌握率或分数线。

生成、更新或核对笔记时，再按 [公共笔记约定](../references/note-contract.md) 组织来源、范围、解释与评价。
