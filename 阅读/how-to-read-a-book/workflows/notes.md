# 生成或更新读书笔记

先读 [公共笔记约定](../references/note-contract.md) 与 [笔记与练习](../rules/notes-and-practice.md) 的 F11、F12；同版本完整内容已在当前上下文时直接复用。本流程用于普通书籍；论文和项目笔记由各自领域流程完成。以下为笔记生成的应用约定，原书依据由上述规则单独维护。

1. 实际打开用户提供的作品和已有笔记，沿用已知目的与范围。区分整书、章节、片段、目录或他人摘要；只有标题时先给合适的笔记框架，等待可读材料后再填写作品内容。
2. 根据已读程度选择分析动作。只做初步了解时按 [检视阅读](inspection.md) 建立结构笔记；论说书精读按 [分析阅读](analytical.md) 组织问题、概念与理由；文学按 [文学阅读](imaginative.md) 组织情节、语言和体验；跨书同题笔记按 [主题阅读](syntopical.md) 处理作者回答及关系。只补足当前笔记缺少且材料支持的部分，不为填模板重复全流程。
3. 用自己的话写出理解，为主要观点、论证及评价提供作品定位；短引保留引用身份。疑问与评价明确写为读者内容。用提纲展示部分之间的关系，避免只有孤立摘句。
4. 更新已有笔记时保留用户仍有价值的记录，用新增材料修正或补充具体位置。确认发现的是误读才修改；新材料与旧结论冲突时解释修订依据，未能判定的分歧保留。文件输出遵循用户的格式和位置；已有文件先读取再编辑。
5. 交付前核对主要观点的来源、适用条件、阅读范围与未解决问题。只有用户另要检验其理解时才进入 [理解核对](understanding.md)，直接要笔记无需通过测验。

笔记可以短到几段，也可以按章节累积；完整程度由已读材料决定，助手完成的笔记不能记作用户独立掌握。
