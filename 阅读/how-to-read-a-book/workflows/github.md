# 交给 GitHub 学习

读取同级 [github-project-learning 入口](../../github-project-learning/SKILL.md)，执行它的学习流程。沿用已有链接、学习目的、经验与运行要求；根据具体材料识别 Git 操作教程、技术教程或项目实现。

论文与实现的联合研究转入 [科研阅读](research.md)，由科研模块安排所需实现任务。普通仓库管理、修复或部署请求按实际任务处理，学习流程不自行扩大为这些任务。

若引用文件缺失，报告实际解析出的具体路径，按 [安装与维护](../INSTALL.md) 恢复同一版本的三个同级目录。可继续已有材料的事实读取；依赖方法尚未加载的部分标明未完成，不能凭记忆补齐后声称套件已执行。
